# Sayu Plugin Loader DLC（早柚插件加载 DLC）

这是「如月怜的游戏连结」（Yomihime Game Link，简称 YGL）面向 AstrBot 的独立 DLC。它计划作为 [YGL Core](https://github.com/yomihime/astrbot_plugin_yomihime_game_link) 的扩展接入，并像 [Steam DLC](https://github.com/yomihime/astrbot_plugin_yomihime_game_link_steam_dlc) 一样单独维护与发布。

项目目标是在不运行早柚核心本体的情况下，兼容并加载早柚核心生态中的部分插件。

项目目前处于初始化与规划阶段，尚未实现兼容层。哪些插件能够加载、需要哪些适配，以及早柚核心的哪些接口需要兼容，都有待研究和验证。
