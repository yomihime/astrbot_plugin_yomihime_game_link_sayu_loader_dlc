# Sayu 插件与 YGL 公共接口之间的缺口

对照基线为 GsCore 0.12.2 和 YGL Core 0.2.11。下列设计供 Core 单独评估。DLC 当前已能使用 `scopes.bind(ctx)` 确认一次 owner 命令，并在本 profile 中保存当前用户提交的数字 UID。该操作只登记用户输入的标识。游戏账户身份、对外请求授权及跨会话发送需要各自的权限。

| 原生插件能观察什么 | 现有宿主边界 | 建议增加的最小行为及验收 |
| --- | --- | --- |
| 同一原生事件可同时命中不同插件的服务，服务优先级及阻断会影响最终执行者 | YGL 的一个命令交给选中的模块。三个包使用各自的身份、配置与资料目录，目前可以比较单个 profile 的回调排序 | 若需跨模块广播，应由宿主向每个获准模块提供同一事件的授权视图，收集候选服务的优先级，然后按既定顺序投递，遇到阻断即停止。通过两个真实注册的服务验证下一条消息的优先级变化，并检查其他模块无法读取前一个模块的私有状态 |
| 匹配到回调并正常返回，插件选择不调用发送接口 | 0.2.11 的结果校验要求成功及部分成功必须包含展示文档。空资料时，上游可能只写日志。DLC 记录没有可投递内容，WebChat 收到不支持提示 | 为命令增加“已处理，无输出”的结果，要求调用确实执行完毕，区分未匹配、抛出异常、权限拒绝与合法零次发送。测试须同时核对调用轨迹、状态写入及收件数为零 |
| 同一事件的机器人、适配器、群、发送人、角色、原始消息段和元事件。文件处理器能读附件 | 文本命令视图有当前调用与用户标识。文件内容、平台权限和完整原始帧不足，普通消息无法区分部分原生角色 | 由宿主为已获准的事件签发资源视图。适配器负责提供经认证的角色与机器人身份。附件以受大小、期限和范围约束的句柄读取。用相同正文、不同发送者和角色比对授权，并在停用或超时后拒绝旧句柄 |
| `Bot.send`、`target_send`、引用、撤回、异步发送队列可观察发送次序及目标侧的结果 | 当前调用可返回一个展示文档。可分页卡片已经能投递一条有序图片链。其他会话的投递、原生多次发送之间的独立引用与逐项确认仍需授权 | 由宿主根据当前会话或既有订阅绑定目标。返回每次发送的顺序、已提交部分、适配器回执和可用的引用。按相同请求标识重试，核对不会重复提交已确认的部分。不支持确认的适配器须明确返回状态 |
| `receive_resp` 与多人应答跨越原指令处理函数，超时、取消及他人回复均有可见区别 | 文本透传只在新的 YGL 命令匹配后得到本次事件，无法接收未命令化的下一条消息 | 提供可取消的会话应答订阅，限制适配器、会话、用户集合、过期时间及代际。对照两个用户交错、超时、退役及同名新会话 |
| 原生账号端口会读取凭据、向指定服务发请求，部分管理回调还会枚举原始记录 | 普通 owner 的数字 UID 私存、身份解析和撤销各有现成接口。任意字符串不能在 YGL 中证明游戏账户所有权，也不能代表管理其他用户的权力 | 将目标发行方、用途、账号、调用方、作用域与期限绑定为可撤销的凭据使用许可，由受信侧完成服务请求。需要原始行的管理回调须另有 profile 管理权限。拒绝跨用户、跨服务、过期、复用旧代际及普通聊天枚举。测试数据使用合成记录 |
| 订阅可定时向平台投递，也可执行会改变游戏服务状态的动作 | 声明式用户订阅支持既有 collector 与 matcher。创建订阅不表示宿主已接受执行外部账户动作。原神自动清红还要求定时向远端确认公告 | 对确需外部写入的任务，单独声明动作、目标、用户授权、取消与重试语义。登记成功、调度执行及外部确认分别记录。用测试服务验证撤销和重复执行，实际账号用途需单独授权 |
| 插件或服务管理、AI 启用后的工具调用、进程池执行可以改变较广范围的状态 | 自身服务开关和优先级、当前 profile 设置、受控线程池及禁用 AI 的注册可在 DLC 处理。宿主级 ACL、模型供应商以及额外进程不会随普通聊天授权 | 管理操作指定可更改的目标和字段。模型调用指定供应商、额度及取消方式。子进程继承本代际代码摘要、文件与网络限制。各自暴露可检查的能力，退役后关闭，实测其他 profile 不受影响 |

真实 WebChat 的测试、内存适配器的原生对照和只有源码定位的项目分别列在[整包对照记录](package-oracle.md)及[契约清单](plugin-contract.md)。原生在普通聊天中返回原始账户列表的行为与 YGL 的用户隔离要求有直接冲突，需要宿主产品决策。
